1. Snake, Water, Gun Game

A simple command-line game written in Python. This is a fun variation of the classic "Rock, Paper, Scissors" game where you play against the computer.

## How It Works
* **Snake** drinks the **Water** (Snake wins)
* **Water** rusts the **Gun** (Water wins)
* **Gun** shoots the **Snake** (Gun wins)

## How to Play
1. Run the `1st_project.py` file in your Python environment or terminal.
2. The game will ask you to enter your choice:
   * Type **s** for Snake
   * Type **w** for Water
   * Type **g** for Gun
3. Press **Enter**.
4. The computer will randomly make its choice, and the screen will display whether you won, lost, or tied!

## Requirements
* Python 3.x installed on your computer.

2.ApplyFlow — Career Application Management System

**ApplyFlow 3.0** is a desktop-based career application management system built with **Python, Tkinter, and SQLite**. It helps users organize, track, and manage job and internship applications in one place.

### ✨ Features

* 📊 **Dashboard** — View total applications, active applications, interviews, and offers.
* 📝 **Application Management** — Add, edit, and delete job/internship applications.
* 🔎 **Search & Filter** — Search applications by company, position, or location and filter them by status.
* ⏰ **Deadline Center** — Track overdue, today's, next 7 days, and upcoming application deadlines.
* 📈 **Analytics** — View response rate, offer rate, interviews, and application pipeline statistics.
* 📊 **Pipeline Overview** — Visualize applications by stages such as Saved, Applied, Interview, Offer, and Rejected.
* 📁 **CSV Export** — Export application data to a CSV file.
* 🌙 **Dark/Light Appearance** — Switch between dark and light themes.
* 💾 **SQLite Database** — Store application information locally using SQLite.

### 🛠️ Technologies Used

* **Python**
* **Tkinter / ttk** — Desktop GUI
* **SQLite** — Local database
* **CSV** — Data export

### 📋 Application Information

Each application can store:

* Company name
* Position
* Location
* Application status
* Deadline
* Applied date
* Application URL
* Notes

### 🚀 How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the ApplyFlow project folder.
4. Run:

```bash
python applyflow.py
```

The application will automatically create the SQLite database when it starts.

### 📌 Project Purpose

This project was created as a **portfolio project** to demonstrate desktop GUI development, database management, CRUD operations, data filtering, analytics, and file export using Python.
