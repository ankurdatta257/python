# Snake, Water, Gun Game

A simple command-line game written in Python. This is a fun variation of the classic "Rock, Paper, Scissors" game where you play against the computer.

## How It Works
* **Snake** drinks the **Water** (Snake wins)
* **Water** rusts the **Gun** (Water wins)
* **Gun** shoots the **Snake** (Gun wins)

## How to Play
1. Run the `1st_project.py` file in your Python environment or terminal.
2. The game will ask you to enter your choice:
   * Type **s** for Snake
   * Type **w** for Water
   * Type **g** for Gun
3. Press **Enter**.
4. The computer will randomly make its choice, and the screen will display whether you won, lost, or tied!

## Requirements
* Python 3.x installed on your computer.
